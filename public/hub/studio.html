                        Settings // heist fund

                        Support button

                        A "buy me a coffee"-style loot-bag button on every page. Add the ways people can send you money, then switch it on.

                          Which services work in Zambia?
                          • Mobile money (MTN, Airtel, Zamtel): the simplest. People send straight to your number.
                          • Card (Visa / Mastercard): create a payment link with a payment company that pays out to you in Zambia (for example Flutterwave, which pays out to mobile money). Paste the link here. Most need ID and some need a registered business.
                          • PayPal: PayPal usually doesn't let Zambian accounts receive money, so only add a PayPal.me link if you've confirmed yours can.
                          • Bank transfer: leave the details empty and visitors will ask for them through the contact form, so your account number isn't public. Or type the details if you're happy for anyone to see them.
