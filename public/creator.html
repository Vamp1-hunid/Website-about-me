Node 02 // Dossier

About me

My name is Mulenga Mwamba, and I am a second-year Bachelor of Science in Data Science student at Mulungushi University in Zambia. I chose Data Science deliberately: I wanted an IT career that would still be well paid and in demand by the time I graduated, without being so saturated that a four-year degree would arrive too late — and it turned out to be challenging enough to hold my interest. My long-term ambition is to become a “unicorn” in tech: data will stay my professional major, but I want real competence across cybersecurity, web development, game development, and machine learning as well. Building this website is a small step in that direction — the web development side of that goal.

Node 04 // Training

My learning plan

I prefer learning from books over live sessions or YouTube — I can scan pages as fast as I want to find exactly what I need and skip what isn't relevant, whereas a video might not even cover what I'm looking for and I have to sit through it to find out.

Steps to improve my web development skills

  1. Work through Learning Web Design: A Beginner's Guide to HTML, CSS, JavaScript, and Web Graphics by Jennifer Niederst Robbins, chapter by chapter
  2. Practise by rebuilding tiny web pages of different formats and content types from scratch, without copying a template
  3. Once HTML/CSS feels solid, move on to a short JavaScript primer focused on DOM manipulation and forms

FILE_01

Semantic HTML5 structure

I rebuilt my personal page with header, nav, main, section and footer elements, one h1, labelled form controls and descriptive image alt text.

  • HTML5
  • Accessibility

DECRYPTED // NOTES

Every input has a label, every photo has alt text that says what it shows, and the page has one h1. A skip link lets keyboard users jump straight to the content.

FILE_02

Responsive CSS design

I styled this site with an external stylesheet, a colour palette kept in CSS variables, media queries for phones, and a light and dark theme.

  • CSS variables
  • Media queries
  • Grid

DECRYPTED // NOTES

All colours live in variables at the top of css/styles.css, so the light theme only swaps those values. Below 760 px the menu folds behind the Menu button.

FILE_03

JavaScript interactivity

I added contact form validation with a local preview, a mobile menu, a theme switch and a study hours calculator, all written in js/script.js.

  • DOM
  • Forms
  • localStorage

DECRYPTED // NOTES

Validation rejects blank and spaces-only text and badly formatted emails. Visitor input is shown with textContent, never as HTML, so it can't run as code.

FILE_04

Full-stack upgrade

The site now has a Node.js and Express server, a PostgreSQL database and member accounts, so I can publish my story art and anime works.

  • Node.js
  • Express
  • PostgreSQL
  • Cloudinary

DECRYPTED // NOTES

Passwords are stored as bcrypt hashes, sessions use secure cookies, and only my admin account can post. Members can comment, like and save favourites.
