## Sections
Introduction, About Me, My Hobbies, My Learning Plan (with a weekly table and a study hours calculator), Projects and Skills, My Photos, My Media (video and audio) and Contact.

## The four JavaScript features
1. **Contact form validation and preview (compulsory):** checks the name, email and message, rejects spaces-only text and badly formatted emails, and shows a local preview. No message is sent.
2. **Mobile navigation:** a Menu button opens and closes the links on narrow screens.
3. **Theme switch:** a button switches between dark and light appearance; the choice is remembered.
4. **Study hours calculator:** turns hours per day and days per week into total weekly hours, and rejects blank, non-numeric, negative or out-of-range values.

## How to test
- Contact form: submit it empty, with spaces only, with the email "abc", then with valid details.
- Mobile navigation: make the browser about 375 px wide and press Menu.
- Theme switch: press the theme button, then refresh the page.
- Calculator: try 2 hours and 5 days (answer 10), then blank, "abc", -2, 0 days and 8 days.
